# Shiren6 Text Mode

Steam版『不思議のダンジョン 風来のシレン6 とぐろ島探検録』のダンジョンを、Rogue風の文字表示にする非公式MODです。地形やプレイヤーに記号を使い、敵には名前の先頭文字、アイテムには「剣」「盾」「巻」「草」などを使います。日本語を含むため、厳密なASCII文字のみの表示ではありません。

## 対応環境と公開版の位置づけ

**v0.5.15は検証環境限定のプレビュー版です。一般の未改造Steam版への対応は未確認です。**

検証した環境はWindows x64、日本語表示、Unity 2022.3.4f1、Steam Build ID 16956985、BepInEx Unity IL2CPP 6.0.0-be.788+5b766a3です。検証環境には別のダンジョン追加MODが導入されています。その環境のGameAssembly.dllは保存されていた.bakと異なるため、配布DLLが未改造環境でも起動するとは限りません。

本MODは起動時にGameAssembly.dllとglobal-metadata.datのSHA-256を照合します。以下の両方に一致する環境だけで文字表示機能が有効になります。Build IDだけでは対応を判定できません。一致しない場合にチェックを無効にして使う方法は提供していません。

| ファイル | 対応SHA-256 |
| --- | --- |
| GameAssembly.dll | `8E50947F6E0B47FAA652E75A8DC65B10B209DC14FFEE0D8FB21B220C0CAB36A2` |
| ShirenTheWanderer6_Data/il2cpp_data/Metadata/global-metadata.dat | `7EE9883EFF203C1CCC030629D417356E5732C921AA5D8A4F10AB2DA80C29AFEF` |

導入前に、同梱の`Test-Compatibility.ps1`で確認できます。このスクリプトは上記2ファイルを読み取り、結果を表示するだけです。ゲームファイルは変更しません。

```powershell
.\Test-Compatibility.ps1 -GameDirectory 'ゲームのインストール先'
```

ソースでは`tools/Test-Compatibility.ps1`にあります。非対応の場合は通常表示で利用し、ゲームのバージョンとチェック結果を添えてIssueで報告してください。ゲーム本体や生成済みのゲームDLLをIssueに添付しないでください。

## 主な機能

- ダンジョン内では文字表示で開始。F9で通常表示と切り替え。
- プレイヤーの向きが分かる矢印、敵名の先頭文字、アイテム種別の漢字、水色の水辺。
- ゲームの視界判定を利用した敵・アイテム表示。探索済みの視界外地形は暗く表示。
- 光る壊せる壁の中身は壊すまで伏せ、通常の壁内にいるモンスターは視界判定に応じて表示。
- HP、満腹度、所持金、メッセージ、メニューを文字化。
- 持ち物の装備マーク、投げ物のセット位置、剣・盾の強さや印を表示。
- Yメニュー下部に装備名、武器と盾の強さ、ちから／最大値、腕輪、経験値を表示。

## 導入

1. ゲームを終了します。既存の本MODがあればDLLと設定を別の場所にバックアップしてください。
2. 上の対応環境を確認します。
3. BepInExが未導入なら、[公式配布ページ](https://builds.bepinex.dev/projects/bepinex_be)の`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.788+5b766a3.zip`を入手します。Mono版やx86版ではありません。[公式導入手順](https://docs.bepinex.dev/master/articles/user_guide/installation/unity_il2cpp.html)に従い、ShirenTheWanderer6.exeと同じフォルダーへ展開し、一度起動して終了します。初回は準備に時間がかかることがあります。すでにBepInExを導入している場合は、既存環境を一括で上書きせず、バージョンと他MODの要件を確認してください。
4. 配布ZIPの`BepInEx`フォルダーをゲームフォルダーへコピーします。追加するファイルは次の2つです。
   - `BepInEx/plugins/ShirenAsciiProbe/ShirenAsciiProbe.dll`
   - `BepInEx/diagnostics/ShirenAsciiProbe/ui-settings.json`
5. Steamから起動し、ダンジョンへ入ります。タイトル画面などは通常表示です。

BepInEx、ゲーム本体、画像・音声、セーブデータ、生成済みinterop DLLは同梱していません。本MODの導入にGameAssembly.dllやUnityPlayer.dllの置き換えは不要です。

更新するときはゲームを終了し、本MODのDLLのみを交換します。設定を編集している場合は、新しい設定との差分を確認し、必要な項目だけ反映してください。旧版の同じDLLを別のpluginsフォルダーに残すと二重読み込みになるため、バックアップはpluginsの外へ置きます。

## 操作

| キー | 動作 |
| --- | --- |
| F9 | ダンジョン内の文字表示と通常表示を切り替え |
| F8 | 問題調査用の診断記録をローカルに作成 |

移動・攻撃・メニューの操作はゲーム本来の操作です。F9で選んだ表示は階層移動後も維持されます。再起動すると文字表示が初期状態に戻ります。階層読み込み中は一時的に通常表示になり、準備後に復帰します。

## 設定と診断記録

`BepInEx/diagnostics/ShirenAsciiProbe/ui-settings.json`でアイコンの文字置換や一部の印の表記を調整できます。設定は約2秒間隔で読み直されます。既定値からの変更は元の設定を保存してから行ってください。

MOD自身は診断情報を外部送信しません。通常時は約5秒間隔で小さな性能集計ファイルをローカルに更新します。F8はUIの文章、階層や敵・アイテム情報などを含む詳細記録を作成するため、公開時は内容を確認してください。記録には画面上では見えない情報が含まれることがあります。調査用F8は通常プレイに必須ではありません。

## 制限と確認状況

- ゲーム更新、別のゲームファイル、他MODとの組み合わせによる互換性は未確認です。
- 現時点ではWindows x64の日本語表示を対象とし、Steam Deckや他言語は未検証です。
- 全ダンジョン・全敵・全印・全画面を網羅した検証はしていません。未対応の印や特殊なUIでは仮の文字や表示崩れが出る場合があります。F9で通常表示を確認できます。
- 元のゲーム画面の上に文字表示を重ねます。3D描画を完全に停止するMODではなく、FPS向上を保証しません。
- 検証環境では視界、壁の中身、向き、水辺、持ち物、印、装備表示、メッセージ、階層移動、Yメニュー下部をプレイ中に確認しています。

## 無効化と削除

ゲームを終了し、`BepInEx/plugins/ShirenAsciiProbe`フォルダーをpluginsの外へ移動すると無効化できます。削除する場合はこのフォルダーを削除します。設定・診断記録が不要なら`BepInEx/diagnostics/ShirenAsciiProbe`も削除できます。他MODが使っている可能性があるため、BepInEx全体は本MODの削除だけを目的として削除しないでください。

## 不具合報告

MODとBepInExのバージョン、互換性チェック結果、再現操作、通常表示と文字表示の違いをIssueに記載してください。必要に応じてゲーム画面の画像を添えてください。セーブデータやゲーム本体を添付する必要はありません。
